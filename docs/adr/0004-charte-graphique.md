# ADR 0004 — Charte graphique

- Statut : accepté
- Date : 2026-11-12

## Contexte

Manora a déjà une identité (site manora-site-vitrine) et une borne existante (ManaBooth) dont l'ambiance doit se retrouver dans Manora Live.

## Décision

- Police unique : Plus Jakarta Sans (titres en 800). Pas de serif ni d'italique décoratif.
- Couleurs reprises du site Manora (`src/lib/theme.ts`) : encre `#132537`, terracotta `#b83a22`, crème `#fffaf1`, sable `#ead8bd`.
- Ambiance ManaBooth pour la borne : grand aperçu caméra arrondi, texte à droite, gros boutons pilule.
- Logo : `assets/images/manora-logo.png` (repris de manora-custom).

## Conséquences

Le back-office reprend les mêmes tokens pour que les trois interfaces se ressemblent.
